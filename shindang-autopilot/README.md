# 신당 오토파일럿

매일 숏폼 한 편을 자동으로 만들고(대본 → AI 영상 → 음성 → 자막) 인스타 릴스·유튜브 쇼츠·X에 올리는 웹앱입니다.
휴대폰 브라우저로 접속해서 설정, 확인, 업로드를 할 수 있어요.

## 1. 설치 (한 번만)

1. Python 3.10 이상 설치
2. FFmpeg 설치
   - 윈도우: https://www.gyan.dev/ffmpeg/builds/ 에서 받아 PATH에 추가
   - 맥: `brew install ffmpeg`
   - 리눅스: `sudo apt install ffmpeg fonts-nanum`
3. 한글 폰트 '나눔고딕' 설치 (윈도우·맥은 네이버 나눔글꼴에서 설치)
4. 이 폴더에서:
   ```
   pip install -r requirements.txt
   ```

## 2. 실행

- 윈도우: `start.bat` 더블클릭
- 맥·리눅스: `./start.sh`

화면에 나온 주소(http://localhost:8000)와 **로그인 비밀번호**로 들어가세요.
비밀번호는 `data/app_password.txt`에도 저장돼 있고, 환경변수 `APP_PASSWORD`로 바꿀 수 있어요.

휴대폰에서 접속하려면 같은 와이파이에서 `http://컴퓨터IP:8000` 으로 들어가세요.
밖에서도 접속하려면 클라우드 서버에 올리거나 Cloudflare Tunnel 같은 도구를 쓰세요 (반드시 HTTPS로).

## 3. 연결할 것

| 서비스 | 어디서 | 웹앱 위치 |
| --- | --- | --- |
| Claude API 키 | console.anthropic.com | 연결 탭 |
| Gemini API 키 (Veo) | aistudio.google.com | 연결 탭 |
| ElevenLabs API 키 + 목소리 ID | elevenlabs.io | 연결 탭 / 설정 탭 |
| 인스타 사용자 ID + 토큰 | developers.facebook.com (비즈니스·크리에이터 계정 필요) | 연결 탭 |
| X 사용자 토큰 | developer.x.com (tweet.write, media.write) | 연결 탭 |
| 유튜브 | 아래 참고 | 터미널에서 1회 |
| 틱톡 Client key + secret | developers.tiktok.com | 설정 → 연결, 그다음 터미널에서 1회 |
| fal.ai 키 (캐릭터 영상, ComfyUI를 안 쓸 때·예비용) | fal.ai | 설정 → 연결 |
| ComfyUI 주소 (3D 캐릭터 영상) | 내 GPU 컴퓨터 ([COMFYUI.md](COMFYUI.md)) | 설정 → 진행 캐릭터 |

**유튜브 연결:** Google Cloud에서 YouTube Data API v3를 켜고, OAuth 클라이언트(데스크톱 앱) JSON을
`data/client_secret.json`으로 저장한 뒤 `python youtube_login.py` 를 한 번 실행하세요.

**틱톡 연결:** 틱톡 개발자 사이트에서 앱을 만들고 Login Kit과 Content Posting API(Direct Post)를 추가해요.
스코프는 `user.info.basic`, `video.publish`예요. Redirect URI를 하나 등록하고, 웹앱에 Client key와 secret을 저장한 뒤
`python tiktok_login.py <등록한 Redirect URI>` 를 실행해 로그인하세요.
**틱톡 앱 심사를 통과하기 전에는 영상이 '나만 보기'로만 올라가요.** 심사 신청은 개발자 사이트의 앱 화면에서 해요.

## 플랫폼 옵션과 라이선스

인스타그램 릴스는 기본이고, 유튜브 쇼츠·틱톡·X는 라이선스에 포함된 것만 켤 수 있어요.
판매자에게 받은 `license_신당이름.json`을 **설정 → 올릴 곳 → 라이선스 파일 올리기**로 넣으면 산 플랫폼이 열려요.
라이선스가 없거나 기간이 끝나면 인스타그램만 쓸 수 있어요.

## 플랫폼별 편집

같은 캐릭터 장면으로 플랫폼마다 편집을 다르게 해서 올려요. AI 요금은 거의 늘지 않아요.

| 플랫폼 | 첫 화면 문구 | 자막 | 길이 | 엔딩 안내 |
| --- | --- | --- | --- | --- |
| 인스타그램 | 호기심 한마디 | 흰 글씨 | 전체 | 댓글 남기면 DM |
| 유튜브 | 검색되는 말 | 노란 굵은 글씨 | 전체 | 고정 댓글 확인 |
| 틱톡 | 호기심 자극 | 반투명 상자, 위쪽 | 전체 | 프로필 링크 |
| X | 짧고 센 한마디 | 흰 글씨 | 3장면으로 짧게 | DM 문의 |

오늘 화면과 상세 화면에서 '인스타 · 유튜브 · X' 버튼으로 편집본을 바꿔 볼 수 있어요.

## 4. 쓰는 법

처음 로그인하면 **처음 설정 마법사**가 열려요. 신당 정보 → 로고·대표색 → AI 키 연결(연결 확인 버튼으로 바로 점검, 목소리 미리듣기·선택) → SNS 연결 → 매일 실행 시각 순서로 따라가면 끝나요. 설정 화면의 '처음 설정 다시 하기'로 언제든 다시 열 수 있어요.

- **오늘**: 오늘 만든 영상을 보고 '확인하고 올리기' 한 번으로 올려요. 만드는 중에는 5단계 진행 상황이 보여요.
- **달력**: 다음 7일 주제를 미리 적어두거나 'AI로 채우기'로 채워요. 적어둔 날은 그 주제로 만들어요.
- **성과**: 인스타그램·유튜브·X의 조회수, 좋아요, 댓글을 모아 보여줘요. 매일 오전 7시·오후 7시에 자동 업데이트돼요.
- **브랜딩**: 로고와 대표색이 앱에 적용되고, 영상 마지막 3초에 로고·신당 이름·예약 문구가 들어간 엔딩 화면이 붙어요.
- **확인하고 올리기 / 바로 올리기**: 만든 뒤 바로 올릴지, 확인 후 올릴지 설정에서 고를 수 있어요.
- Veo 생성이 실패하면 `backgrounds/` 폴더의 mp4 중 하나를 대신 써요 (없으면 단색 배경).

## 5. 진행 캐릭터 (애기동자·선비·선녀·무당)

캐릭터 모드를 켜면 캐릭터가 직접 말하는 영상을 만들어요.
- **진행 방식**: '여럿이 번갈아' 또는 '한 명이 혼자'(예: 무당 혼자 "딱 하루 있어. 딱 세 가지만 짚어줄게." 식으로 진행)
- **자막**: '말에 맞춰 짧게 크게'를 고르면 ElevenLabs가 알려주는 글자별 타이밍에 맞춰 2~4단어씩 크게 바뀌어요. '문장 단위로'도 고를 수 있어요.
- **움직임**: 캐릭터마다 손짓·소품 동작 설명(영어)을 적어두면 입 모양 맞출 때 같이 반영해요. 실제로 얼마나 움직이는지는 모델에 따라 달라서, 손동작이 중요하면 고화질 모델로 시험해 보세요.
- **이미지 올리기**: 가로로 넓은 그림을 올려도 세로 9:16 화면에 맞춰 넣고 남는 곳은 흐리게 채워요. 그래도 정면 상반신 세로 이미지가 입 모양이 가장 잘 맞아요.

1. 설정(또는 처음 설정 4단계)에서 캐릭터마다 **AI로 이미지 만들기**를 누르면 후보 2장이 나와요. 마음에 드는 걸 **이걸로**를 눌러 고르면 매일 그 얼굴로 나와요. 가지고 있는 이미지를 올려도 돼요.
2. 캐릭터마다 목소리를 고를 수 있어요. 비워두면 목소리 목록에서 서로 다르게 자동 배정돼요.
3. 매일 Claude가 캐릭터별 대사를 쓰고 → ElevenLabs가 캐릭터 목소리로 읽고 → fal.ai의 Kling AI Avatar가 이미지에 입 모양을 맞춰요.
4. 대사가 끝나면 3초짜리 엔딩 화면(로고·신당 이름·예약 문구)이 붙어요.

- 필요한 키: **FAL_KEY** (fal.ai 대시보드에서 발급). 입 모양 맞추기가 실패한 장면은 캐릭터 이미지가 천천히 확대되는 화면으로 대신해요.
- 비용: 기본 모델 초당 약 $0.056, 고화질 초당 약 $0.115 (2026년 10월 fal.ai 표시 가격). 하루 25초짜리 한 편이면 기본 모델로 월 약 $40예요. 캐릭터 모드에서는 Veo 장면 영상을 만들지 않아서 Veo 비용은 나가지 않아요.
- 정면을 보는 상반신 이미지여야 입 모양이 잘 맞아요.
- 캐릭터는 모두 가상 인물이에요. 캡션에 'AI 캐릭터가 등장하는 영상'이라고 들어가고, 유튜브에는 AI 생성 콘텐츠 표시가 켜져요.
- 실사풍 아이 캐릭터는 AI 서비스에서 막히는 경우가 많아서, 애기동자는 동화책 느낌으로 설정해 뒀어요.

## 5-1. ComfyUI로 3D 영상 만들기 (내 GPU 컴퓨터)

설정 → 진행 캐릭터 → **3D 영상 만드는 곳**에서 '내 컴퓨터 ComfyUI (3D)'를 고르면, 캐릭터가 말하는 장면을
fal.ai 대신 내 컴퓨터의 ComfyUI(Wan 2.2 S2V)로 만들어요. 영상 생성 비용이 들지 않고, 3D 애니메이션풍으로 나와요.
ComfyUI가 꺼져 있으면 fal.ai(키가 있을 때) → 정지 화면 순서로 대신해요.
설치·모델·연결 방법은 **[COMFYUI.md](COMFYUI.md)** 를 보세요.

## 6. 주의

- 컴퓨터가 꺼져 있으면 자동 실행이 안 돼요. 항상 켜두거나 클라우드 서버를 쓰세요.
- `data/` 폴더에 API 키가 저장돼요. 다른 사람과 공유하지 마세요.
- 유튜브 고정댓글은 API로 고정할 수 없어서 댓글만 달아요. 스튜디오에서 '고정'을 눌러주세요.
- 인스타·유튜브 자동 DM 문구는 기록 탭에 저장돼요. 실제 자동 DM 발송은 ManyChat 같은 도구에 붙여 넣어 쓰세요.
